# Pablo Dev Garrido — Portfolio

Portfolio estático creado con Astro y TypeScript. El contenido de proyectos vive en `src/data/projects.ts`: para agregar uno nuevo, incorporar otro objeto con la misma forma; la grilla se actualiza sin modificar componentes.

## Desarrollo

```bash
npm install
npm run dev
npm run build
npm run preview
```

La información de Fichero Online y Procesador de Facturas IA fue revisada en sus READMEs públicos el 05/11/2026. Pipeline de Documentos IA usa la descripción confirmada por el usuario y mantiene una nota editable porque el repositorio es privado.
